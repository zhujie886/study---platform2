🔍 术语解释 (什么是孤岛问题？)

孤岛文件 (Orphan File)：指的是那些静静地躺在你的文件夹里，但是没有任何其他文件 import 它们的文件。就像一座没有桥梁连接的孤岛。这通常意味着：1. 你写了组件忘了用；2. 这是被遗弃的旧代码；3. 入口文件名写错了导致没连上。

断链引用 (Broken Link)：你试图 import X from './X'，但 ./X 根本不存在。这是导致 React 白屏的最常见原因。
